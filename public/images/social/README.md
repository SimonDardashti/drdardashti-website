# Social Media Images

Graphics optimized for social media platforms and Open Graph sharing.

## Purpose

Create eye-catching, shareable content for social media and open graph preview cards when links are shared.

## Image Types

- Open Graph images (link previews)
- Twitter card images
- LinkedIn graphics
- Facebook post graphics
- Instagram-style graphics
- Blog post preview images
- Article preview cards
- Quote graphics
- Tip/advice graphics
- Educational infographics
- Testimonial graphics
- Event promotion graphics

## Specifications

**Open Graph (general link preview):**
- Dimensions: 1200x630px
- Aspect ratio: 1.91:1
- Format: WEBP or PNG

**Twitter Card:**
- Dimensions: 1200x675px
- Aspect ratio: 16:9
- Format: WEBP or PNG

**LinkedIn:**
- Dimensions: 1200x627px
- Aspect ratio: 1.91:1
- Format: WEBP or PNG

**Facebook Post:**
- Dimensions: 1200x628px
- Aspect ratio: 1.91:1
- Format: WEBP or PNG

**Instagram:**
- Dimensions: 1080x1080px (square)
- Format: WEBP or PNG

**General Social:**
- Minimum 800x420px
- Format: WEBP or PNG
- Background: Branded, professional
- Text: Readable at small sizes
- Branding: Include site/physician branding

## Naming Convention

Structure: `[content-type]-social-[platform].webp`

**Examples:**

- `mcgill-exercises-social-og.webp` - Article Open Graph
- `conservative-care-social-twitter.webp` - Twitter card
- `pain-relief-tips-social-linkedin.webp` - LinkedIn graphic
- `low-back-pain-social-facebook.webp` - Facebook post
- `exercise-tips-social-instagram.webp` - Instagram graphic
- `treatment-guide-social-og.webp` - Guide preview
- `testimonial-social-quote.webp` - Patient quote
- `patient-education-social-og.webp` - Hub page preview

## Usage

Used for:
- Open Graph preview when links are shared
- Twitter/X card previews
- LinkedIn article shares
- Facebook post images
- Instagram story/feed posts
- Blog social promotion
- Email newsletter graphics
- Marketing materials

## Technical Notes

- Optimize file size for quick loading
- Use readable fonts at reduced sizes
- Include call-to-action if applicable
- Test rendering on various platforms
- Ensure brand consistency across all social graphics
