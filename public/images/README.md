# Medical Image Asset Library

Permanent repository for all medical, anatomical, procedural, and educational imagery used throughout the drdardashti.com website.

## Directory Structure

### `/anatomy/`
Medical illustrations of human anatomy (spine, nerves, joints, muscles)

### `/conditions/`
Visual representations of pain conditions (spine, nerve, joint, headache)

### `/procedures/`
Illustrations of interventional procedures (injections, ablation, neuromodulation, regenerative)

### `/conservative-care/`
Images for conservative treatment methods (exercises, physical therapy, aquatic therapy, tai chi, meditation, biofeedback, CBT)

### `/flowcharts/`
Decision trees, treatment pathways, and diagnostic flowcharts (SVG format)

### `/comparison/`
Before/after, side-by-side comparisons of conditions or treatments

### `/icons/`
UI icons and visual indicators for the website

### `/physician/`
Professional headshots and credentials photography

### `/social/`
Social media graphics, Open Graph images, and social cards

## Global Standards

**Preferred Format:** WEBP (modern, optimized)  
**Fallback Format:** PNG (broader compatibility)  
**Flowchart Format:** SVG (scalable, responsive)

**Naming Convention:**
- Lowercase only
- Hyphen-separated words
- Descriptive and specific
- No spaces or underscores
- Include body region/type when relevant

**Example Filenames:**
- `lumbar-spine-anatomy.webp`
- `cervical-dermatomes.webp`
- `epidural-steroid-injection.webp`
- `mcgill-big-3-exercises.webp`
- `thoracic-foam-rolling.webp`

## File Organization

Each subfolder contains a README.md with:
- Specific purpose and use case
- Recommended image dimensions
- Exact file format requirements
- Folder-specific naming conventions
- Example filenames for that category

## Quality Standards

- All medical illustrations should be professionally rendered
- Images must be appropriate for healthcare website (HIPAA-compliant, professional)
- Responsive design: provide multiple sizes if needed
- Accessibility: all images used on site must have descriptive alt-text
- Physician-approved: medical content reviewed for accuracy

## Usage

Images in this library are organized by content category. When adding images to pages:

1. Place files in appropriate subfolder
2. Use naming convention consistently
3. Add to applicable folder README examples
4. Always include descriptive alt-text on website
5. Optimize file size before deployment
