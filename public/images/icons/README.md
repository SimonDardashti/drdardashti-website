# Icon Images

Website UI icons and visual indicators for navigation, features, and categories.

## Purpose

Provide consistent, professional icons for website navigation, service categories, and visual hierarchy.

## Image Types

- Navigation icons
- Service category icons
- Feature indicators
- Condition category icons
- Procedure type icons
- Treatment type icons
- Educational content icons
- Success/completed indicators
- Alert/warning icons
- Arrow and directional icons
- Medical symbols
- Status indicators

## Specifications

- **Dimensions:** 24x24px, 32x32px, 48x48px, 64x64px (provide multiple sizes)
- **Format:** SVG preferred for scalability, PNG as fallback
- **Background:** Transparent
- **Style:** Minimalist, professional medical aesthetic
- **Strokes:** Consistent line weight (2px typically)
- **Color:** Match site color scheme (gold #c8a020, black #0a0a0a, grays)

## Naming Convention

Structure: `[icon-name]-[size].[format]`

Or for SVG: `[icon-name].svg`

**Examples:**

- `spine-condition-icon.svg` - Spine condition marker
- `procedure-icon.svg` - Procedure indicator
- `exercise-icon.svg` - Exercise activity
- `conservative-care-icon.svg` - Conservative treatment
- `meditation-icon.svg` - Mindfulness/meditation
- `pain-relief-icon.svg` - Pain management
- `check-mark-icon.svg` - Completion indicator
- `alert-icon.svg` - Alert/warning
- `arrow-right-icon.svg` - Next/forward indicator
- `heart-health-icon.svg` - Health/wellness

## Usage

Used throughout:
- Navigation menus
- Category listings
- Service highlights
- Feature indicators
- Status markers
- Educational content
- Call-to-action buttons

## Technical Notes

- Use SVG for responsive scaling across devices
- Ensure proper contrast for accessibility
- Test at various sizes for legibility
- Maintain consistent visual weight across icons
